# Overlay - root person

Use this overlay when the root entity is an individual person's operational
memory.

## Quadrant Placement Guardrail

- Social contexts are Q3 only when they preserve lived relationships, shared
  meaning or mutual expectations; an externally administered affiliation,
  account, routine or process is Q4.
- Communication channels such as email, calendar, Drive and chat are Q4 as
  coordination systems. A specific exported message, document or artifact can
  be Q2 when it is evidence/output, or Q3 when it preserves relationship
  meaning.
