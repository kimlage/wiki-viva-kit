# Wiki Templates

Reusable page contracts and authoring conventions for wiki viva pages.

Use these templates when creating typed pages, PR checklists, relationship maps,
dashboards, source pages and public/private publication notes.

- [Context entry](context-entry.md) and [context hub](context-hub.md):
  instructions and map for a folder, including links to sources and repos.
- [Source](source.md) and [source config](source-config.md): canonical source
  identity and the existing mechanically consumed recipe.
