# Wiki Templates

Reusable page contracts and authoring conventions for wiki viva pages.

Use these templates when creating typed pages, PR checklists, relationship maps,
dashboards, source pages and public/private publication notes.

[Context instructions](context-instructions.md) use the existing
[section contract](context-instructions.yaml). The [modular template guide](../../guides/modular-template-sections.md#context-instructions)
explains creation, validation and consumer registration. The kit's own
[development instructions](../../../../AGENTS.md) are not a consumer policy.
