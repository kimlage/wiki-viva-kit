# Choose the integrated experience architecture

Type: grilling
Mode: HITL
Status: open
Blocked by: 07, 08, 10, 11
Owner: Kim

## Question

Which tested architecture makes 3D necessary for orientation and consequence
while keeping 2D necessary for evidence and decision?

The decision must cite the prototype verdicts, measured budget, accessibility
behavior and the failure modes of the rejected alternative. Visual taste alone
is insufficient. A combined answer is valid only when it gives each grammar an
exclusive responsibility instead of stacking three skins.

## Review protocol

Open each variant in a fresh reload and complete the same loop. Score four
questions from one to five:

1. Could I relocate the East tension after opening and closing the evidence?
2. Did 2D add precision without making the 3D feel abandoned?
3. Did the authorized consequence feel local, legible and earned?
4. Would I repeat this verb for a real source without fatigue?

Then switch variants without reloading to judge whether the preserved session
still feels like one world or three separate applications.

## Provisional integration hypothesis — not a decision

The strongest combined thesis is direct scales as the navigation chassis,
topographic table as the district relationship grammar and organism behavior
only as localized feedback after a receipt. This combination is valid only if
the three roles remain exclusive. Reusing all three as interchangeable skins
would multiply implementation cost and destroy spatial memory.
