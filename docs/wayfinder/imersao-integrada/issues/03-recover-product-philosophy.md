# Recover the product philosophy and technical seam

Type: research
Mode: AFK
Status: resolved
Blocked by: none
Owner: Codex research thread, 2026-07-30

## Question

Which product principles must survive the visual reset, and which technical
seam offers the smallest implementable integration of 3D and 2D?

## Answer

The game happens in real life. A source is an ongoing pulse, perspectives reveal
contrasts without becoming truth, and useful progress is verified capability
rather than collection or screen time.

The complete operational loop is:

`source → perspective → tension → mission → action → evidence → human gate → receipt → localized world mutation`

The player is a guardian or gardener, not a conqueror. Agents may propose and
operate within explicit capabilities; humans grant meaning, authority and
publication. Every important visual mark must resolve to data, rule, module or
receipt and must have a textual alternative. Time is evidential: the system must
not invent a continuous replay between observed states.

The current code already has the right lower seam: 2D and 3D share semantic IDs,
selection, routes and events through the world runtime. The expensive seam is
presentation: large scene, world, perspective and stylesheet modules encode too
many metaphors before one extensible interaction has been proved.

The leading architecture is **persistent world plus focus surface**:

1. Select one source, tension, mission or receipt in the world.
2. Preserve the same entity and state while a 2D surface emerges from its
   projected location.
3. Let the surface dock for precision while maintaining a visible relation to
   the world object.
4. Review or act in 2D.
5. Return to the same spatial focus and see only the verified mutation.

Working rule: 3D answers **where and what changed**; 2D answers **why, according
to which evidence, and what may be decided**.

Two alternatives remain useful as prototypes: an orthographic topographic table
for lower complexity, and three exclusive scales (orbit, district, interior)
only if a single focus session proves insufficient.
