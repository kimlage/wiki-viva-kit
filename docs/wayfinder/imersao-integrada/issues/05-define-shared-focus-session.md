# Define the shared 3D and 2D focus session

Type: grilling
Mode: HITL
Status: open
Blocked by: 04
Owner: unclaimed

## Question

Which state must remain continuous while the player moves from spatial
orientation to precise evidence and action?

Recommended starting answer: define one `FocusSession` carrying the selected
entity, perspective, observed time, surface phase, spatial anchor and pending
decision. The world remains mounted; only the focus surface changes depth.

This ticket must decide what belongs in the shared semantic state and what is
merely camera or presentation state.
