# Synthetic context hierarchy

The single [manifest](hierarchy.json) models finance, independently interpreted tax and costs, a personal company perspective, and a separate company domain. Sibling access is not implicit. Context roots are path-prefix boundaries, not glob patterns; `self` expands at the declaring context. Missing permissions inherit, empty lists deny, and denies accumulate. Parents must already allow a scope before a child may specify it. To share a selected path or section, the approved producer export and consumer import must match exactly, including use, classification and expiry; both effective read policies must allow the path. A proposal is pending and grants nothing.

Pass an independently approved Git revision to the CLI; choosing a commit is not proof of approval. Policy and mandatory rule content come from that revision, even when evidence comes from historical content. The caller is responsible for authenticating its adapter report; the policy does not enforce an operating-system sandbox. Packet byte budgets count selected UTF-8 content, and overflow is an error. Dynamic query fingerprints and omissions are caller-supplied coverage records, not proof of completeness.
