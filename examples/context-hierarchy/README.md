# Synthetic context hierarchy

The [root manifest](context.yaml) and descendant `context.yaml` files models finance, independently interpreted tax and costs, a personal company perspective, and a separate company domain. Sibling access is not implicit. Context roots are path-prefix boundaries, not glob patterns; `self` expands at the declaring context (`.` is the repository root). Missing permissions inherit, empty lists deny, and typed read, write, capability and publication denies accumulate. Parents must already allow a scope before a child may specify it. To share a selected path or section, the approved producer export and consumer import must match exactly, including use, classification and expiry; both effective read policies must allow the path. A proposal is pending and grants nothing.

Pass the current independently approved Git revision and the root manifest path to the CLI; choosing a commit is not proof of approval. Policy and mandatory rule content come from that revision, even when evidence comes from historical content. The caller is responsible for authenticating its adapter report; the policy does not enforce an operating-system sandbox. Packet byte budgets count selected UTF-8 content, and overflow is an error. Dynamic queries are rejected; explicit read sets state missing coverage without claiming completeness.
