# Study and Research conformance pack

This declarative pack proves the full experience-pack contract with synthetic,
low-privacy study material. It contributes typed knowledge objects, templates,
registered view and operation slots, three temporal profiles, EN and PT-BR copy,
four public fixtures and a versioned empty asset manifest ready for separately
approved, licensed and hashed assets.

The pack reuses the core `quadrant_lenses` and `gamification` block packages.
It does not add executable code or alter the core secret, privacy or publication
gates. Installed user pages remain in the wiki when the pack is disabled or
removed.

Its v2 temporal adapters expose learning capture/review, spaced-review due
dates and claim recorded/verified/superseded history with explicit evidence
provenance. Dense and conflicting-evidence fixtures are compiled by the trusted
core fixture compiler, never by pack-owned scripts.
